# Test fixtures

Phase 1 manual testing uses `dungeon-map-for-testing.png` for map upload / grid checks.

`tiny-map-for-unit-tests.png` is a small PNG for automated upload tests.

`tiny-map-for-unit-tests.dd2vtt` is a small Universal VTT file (embedded tiny PNG + sample walls) for parser and upload unit tests.

`dungeon-map-for-testing.dd2vtt` is a full Universal VTT export (embedded image, grid, walls). Use it for manual Settings → Maps import checks.

`dungeon-map-animated-for-testing.webm` is kept for a later animated-layer milestone; not wired yet.
