# Playing — DMs-only-Friend

## Roles

- **GM** — laptop at the table. Use **Settings** to prep, **Play** to run the fight.
- **Screen** — TV/tablet board. Map only + initiative rail. Camera follows the GM.
- **Player** — remote join with your name; move only your PC token when it matches your name.

## GM prep (Settings)

1. Create a room and open the GM link.
2. Upload one or more maps; set each map’s `grid_px`.
3. Copy Screen / Player links for the table.
4. Add PCs and NPCs; tick which maps each character appears on.
5. Switch to **Play** when the session starts.

## GM play

Floating islands around the map:

- **Map** — change active map; show/hide PCs or NPCs as groups.
- **Initiative** — enter scores, set order, next turn (round advances when the order wraps).
- **NPCs** — spawn or place roster NPCs on the current map.

Drag an island’s **Snap** control to cycle corners. Positions are remembered for this room in the browser.

Changing the active map brings in characters linked to that map (and drops the others).

## Screen / player

No GM islands. Use the side rail for round, turn order, and whose turn it is. Follow the GM’s pan/zoom.
